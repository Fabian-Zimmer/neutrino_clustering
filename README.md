# N-1-Body CNB Simulation Code

**Authors:** Fabian Zimmer, Camila Correa, Guillermo Franco Abellán, Shin'ichiro Ando

## Version 1.0

Repository containing codes to run relic neutrino simulations, which were specifically designed for the work of [2306.16444](https://doi.org/10.48550/arXiv.2306.16444). The scripts have also been designed to be interfaced with data from [2206.11298](https://doi.org/10.1093/mnras/stac2830) present on the Snellius Computing Clusters at SURFsara in the Netherlands. 

## Version 2.0

The runtime of the simulations has been significantly reduced with the use of the JAX, diffrax and chex libraries. 

Used for the works of [2407.14582](https://doi.org/10.48550/arXiv.2407.14582) and [2507.01505](https://doi.org/10.48550/arXiv.2507.01505).

## Comments

The repository contains scripts for running the simulations, analysing their output, and various other statistical analyses. As it was designed for myself and my collaborators, it is not a production-level code. For any questions about the codes and functions necessary to run such simulations or produce the figures in one of the above papers, please contact fabiantje.zimmertje@gmail.com
